# Grade

服务上海中考学生与家庭的学习记录应用：录入考试成绩、对照目标、从题目证据定位薄弱点、安排练习并用复测验证效果。正式版核心闭环已实现，前端在原型基础上移植，保留桌面/手机同一套响应式页面。

## 已实现

- **账号与家庭**：首次启动创建管理员和第一个家庭；管理员新增家庭、家长/学生账号、管理员权限、启用/停用、一次性临时密码重置。账号按家庭隔离，管理员不读取其他家庭成绩。
- **权限**：家长维护考试、排名、学习设置和中考计分；学生查看成绩/目标，参与复盘、练习和复测；学生不能保存分数、计分或设置。
- **考试录入**：单元/阶段/期中期末/模拟中考/其他；模拟中考固定 750 分制，缺科显示已录小计且不参与完整总分比较；其他考试按实际录入科目求和；支持未考/待公布/缺考状态；班级/年级名次与“前 x%”按该场参考人数快照计算。
- **成绩对照**：近 5 场、目标对照、卷面失分；历史考试始终对照当前目标；单科比较遇到类型/范围/满分变化显示“口径变化”。
- **考后复盘**：按学科记录题号、得分、满分、知识点、技能、题型、已确认错因；自动汇总已记题目失分并提示与卷面失分不一致。
- **本周行动**：从题目证据安排练习，记录正确题数/总题数、原题/新题、独立/提示完成和复测发现；能力页按近 5 场知识点/技能矩阵回看证据和复测。
- **中考计分**：2026 上海中考 15 个计分项目，满分 750；家长填写，学生只读。
- **学习设置**：学习档案、班级/年级人数、阶段排名目标、各科目标得分率；人数只影响之后的新考试，历史考试保留快照。
- **演示数据**：任何账号可切换到“演示数据”查看只读示例，不写入数据库；切回“我的记录”只看本家庭数据。

## 快速开始

```bash
cd /home/lingy/lyai-project/grade
python3 -m venv venv
./venv/bin/pip install -r requirements-dev.txt
./venv/bin/python run.py
```

打开 <http://localhost:5000>，首次进入会显示初始化页面：填写家庭资料和管理员账号，完成后自动登录。

- 开发入口：`run.py`（默认 `0.0.0.0:5000`，`GRADE_DEBUG=1` 开启 Flask 调试）
- 生产入口：`serve.py`（Waitress，默认 `0.0.0.0:9102`）
- 数据库：默认 `data/grade.db`，首次启动自动建表
- 重置本地数据：停止服务后删除 `data/grade.db`、`data/grade.db-wal`、`data/grade.db-shm`（会删除全部账号与记录，谨慎）

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `GRADE_DATA_DIR` | `./data` | 数据目录，存放数据库与默认密钥文件 |
| `GRADE_DATABASE` | `$GRADE_DATA_DIR/grade.db` | SQLite 文件 |
| `GRADE_SECRET_KEY` | 自动生成 `$DATA_DIR/secret_key` | Flask 会话签名密钥；生产建议显式设置 |
| `GRADE_SECRET_KEY_FILE` | `$DATA_DIR/secret_key` | 密钥文件路径 |
| `GRADE_COOKIE_SECURE` | `0` | HTTPS 生产设为 `1` |
| `GRADE_COOKIE_PATH` | `/` | 子路径部署时可配合 Nginx 重写 |
| `GRADE_HOST` | `0.0.0.0` | 监听地址；生产建议 `127.0.0.1` |
| `GRADE_PORT` | `5000`（run）/ `9102`（serve） | 监听端口 |
| `GRADE_THREADS` | `4` | Waitress 线程数 |
| `GRADE_DEBUG` | `0` | 仅开发入口使用 |

## 账号与权限模型

- **家庭**：一名在读学生 + 若干家长账号；同一家庭共享一份学习记录。
- **角色**：`parent`（家长）/ `student`（学生）；管理员权限是独立附加位，可与任一角色组合。
- **初始化**：数据库无账号时 `/setup` 可创建首个管理员（家长角色）和第一个家庭；创建后初始化入口自动关闭。
- **新账号**：管理员创建时生成一次性临时密码；对方首次登录必须修改。管理员重置密码会使用户现有会话失效。
- **约束**：至少一名启用的管理员；不能停用当前账号；用户名大小写不敏感唯一。
- **边界**：管理员可新增家庭、修改家庭名称、创建/编辑账号；学生档案（称呼/年级/班级）由家长在「学习设置」维护。
- **隐私**：管理员只能看到家庭名称、学生称呼/年级/班级和账号身份，不提供任何跨家庭成绩读取接口。

## 数据口径

- **模拟中考**：总满分固定 750；各科使用 2026 模板合计满分（语数英 150、物理 80、化学 55、道法 60、历史 60、跨学科 15、体育 30）。缺科时总分为已录小计，且签名置空，不参与完整总分比较。
- **其他考试**：按实际录入科目的得分与满分分别求和；总分比较要求考试类型、参考范围、各科满分签名一致。
- **考试状态**：未考/待公布/缺考不产生得分，不按 0 分计入；真实录入的 0 分是有效成绩。
- **排名占比**：名次 ÷ 该场参考人数；缺人数不估算。
- **人数快照**：新考试保存当时的班级/年级人数；之后修改设置不重算历史考试。
- **目标**：家庭自定义，历史考试也对照当前目标；目标不代表录取线或能力诊断。

## 安全

- 会话 Cookie：HttpOnly、SameSite=Lax，生产可加 Secure。
- 所有写接口要求会话内 CSRF token（`X-CSRF-Token`）；登录/初始化/改密表单使用隐藏 token。
- 密码使用 Werkzeug `scrypt` 哈希；不存明文。
- SQL 全部参数化；家庭级查询统一带 `family_id`。
- 响应头：CSP、`X-Frame-Options: DENY`、`nosniff`、`Referrer-Policy: same-origin`。
- 登录失败按 IP+账号做 10 分钟窗口限流（进程内，单 Waitress 进程有效）。
- 生产部署文档仅保存在本地运维环境，不纳入版本库。

## 当前边界

- 中考计分模板固定为 2026 年；年度模板维护未实现。
- 导入/导出、备份恢复界面未实现。
- 密码找回依赖管理员重置，无邮件/短信找回。
- 登录限流为单进程内存状态；多进程部署需要外部限流。
- schema 结构变更通过 `app/db.py:_migrate` 按版本迁移；当前版本 3。
- 管理员可管理账号身份，但不能查看其他家庭的学习数据。
